# Changelog

本项目的所有变更都记录在此文件：每行一条，格式为「类型 日期 描述」，类型取 `新增`／`优化`／`修复`，最新的变更排在最上面，不再按版本号分组。

- 修复 2026-11-11 嵌入的纯文件编辑器扩展（Excalidraw 等）现在按文件编辑器入口打开并注入空白文档，不再白屏，可直接画图；旧标签无需重开也会自动恢复
- 修复 2026-11-11 嵌入扩展的宿主订阅按作用域去重，workspace 与 shells 订阅共享同一条宿主通道，同时打开多个标签不再触发“At most 32 workspace subscriptions per frame”，Task Board 等面板正常加载
- 修复 2026-11-11 嵌入扩展的宿主桥补上“附加到聊天”与目录切换转发，Canvas 的产物引用可进入输入框，切换项目时内嵌面板同步更新范围
- 修复 2026-11-11 嵌入扩展的宿主桥补上服务状态转发，Canvas 等扩展在 OpenWith 中打开设置页时不再报“尚未桥接 service-status”
- 修复 2026-11-11 嵌入的扩展现在跟随宿主会话切换，Agent progress 在 OpenWith 中显示当前会话的报告进度，不再一直停在“未选择会话”
- 修复 2026-11-11 嵌入扩展按扩展自己声明的面板入口加载，Agent progress 等非 panel/index.html 入口的扩展不再空白
- 修复 2026-11-10 扩展市场紧凑视图恢复显示扩展图标与一行简介，不再只剩名称和按钮
- 优化 2026-11-10 扩展市场补齐缺少的中文简介，并为 timer／map 类内置图标补上图形，加载缓存时也会自动补译
- 修复 2026-11-10 扩展市场目录写入磁盘缓存并缩短抓取校验时间，冷启动和重启后不再因宿主 20 秒超时而加载失败，失败时自动重试并可直接重新加载
- 新增 2026-11-10 扩展列表每行新增“卸载”按钮，确认后调用宿主卸载扩展并关闭对应标签
- 优化 2026-11-10 “+ 新标签”菜单改为紧凑列表，展示全部已启用扩展及其图标、版本，网址与日志／终端入口收在列表下方
- 新增 2026-11-09 矩阵主页新增“扩展市场”标签，聚合官方目录与 GitHub 社区扩展，按官方精选／社区／工具与集成／主题与界面／MCP 与连接器／实验与其他筛选，显示星标、更新时间、仓库与主页链接，可直接一键安装
- 修复 2026-11-09 扩展市场的列表与紧凑视图现在真正切换布局，紧凑视图压缩为单行条目，不再只有卡片样式
- 修复 2026-11-09 扩展市场改用扩展自身的图标（官方目录内联图标或仓库 icon.svg），不再显示仓库作者头像；没有图标文件时使用扩展声明的内置图标，否则显示名称首字
- 优化 2026-11-09 扩展市场简介补充中文翻译，点击扩展卡片可直接打开对应仓库，搜索同时匹配中文简介
- 优化 2026-11-09 扩展与市场图标统一为同尺寸浅色圆角底板，白色描边图标自动反色，深浅主题下图标风格保持一致
- 修复 2026-11-08 扩展图标为黑色或白色 SVG 时自动匹配浅色／暗色底，深色主题下不再与图标底色融在一起；宿主主题变化后自动重新检测
- 修复 2026-11-08 扩展列表的版本号、安装方式、更新地址、分类标签等辅助文字改用宿主文本色，不再套用表面色，避免与背景同色不可见
- 修复 2026-11-08 面板检测宿主前景色与背景色对比度，过低时自动回退到可读的深/浅色主题，避免黑字黑底
- 优化 2026-11-07 扩展库按工作台、开发、AI、记忆、监控、基础设施、主题分类，支持分类标签筛选与分组展示
- 优化 2026-11-07 扩展条目显示真实图标、版本、分类、安装方式与更新地址，窄面板下操作区自适应换行
